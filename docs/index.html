OpenGS Map Tool

Generate province and territory maps for grand strategy games from real-world boundary data

Install

Debian 13 (trixie) / Linux

# System dependencies
sudo apt install python3-pyqt6 python3-numpy python3-pillow \
    python3-scipy python3-tk python3-venv gdal-bin

# Clone and setup
git clone https://github.com/cpntodd/opengs-maptool.git
cd opengs-maptool
python3 -m venv --system-site-packages .venv
.venv/bin/pip install tkinterdnd2 cartopy

# Run
.venv/bin/python3 main.py

Windows

Download the latest release from GitHub Releases, unpack, and run the executable.

Features

Map Import

Load real-world administrative boundaries from GeoJSON or MapInfo TAB files. Auto-generate land/sea raster images from Natural Earth coastline data. Supports multi-file loading with automatic clipping to land.

Territory Generation

Generate territory maps from land and boundary images. Control land and ocean territory counts independently with density sliders.

Province Generation

Subdivide territories into provinces using Voronoi tessellation with Lloyd relaxation for natural-looking regions.

Density Control

Import density images to control province/territory distribution. Darker areas attract more seeds for denser regions.

Jagged Borders

Optional natural-looking irregular borders using spatially-correlated noise instead of straight Voronoi edges.

Terrain System

Import a terrain image to assign terrain types (forest, desert, mountain, etc.) to provinces based on their center-point location.

Lake Support

Lakes are automatically detected and become individual provinces, assigned to the overlapping territory.

Export

Export territory and province maps as PNG images, plus JSON definitions with IDs, RGB colors, types, coordinates, and terrain data.

Usage

Map Import Tab

The quickest way to create a map from real-world data:

  1. Click Load Boundaries... and select one or more .tab or .geojson files
  2. Boundaries are auto-converted (TAB via GDAL) and auto-rasterized
  3. Click Generate Land Image to create a coastline-based land/sea raster
  4. Click Send to Boundary Tab to push the rasterized boundary to the pipeline
  5. Use Add Boundaries... to append additional files to the current set
  6. Enable Clip to Land to prevent boundaries from extending into the ocean

Full Pipeline

  1. Map Import or Land Image tab -- provide a land/sea raster (ocean = RGB 5,20,18)
  2. Boundary Image tab -- provide administrative borders (black = RGB 0,0,0)
  3. Density Image tab -- optional density map for province distribution control
  4. Terrain Image tab -- optional terrain type assignment
  5. Territory Image tab -- generate territories, adjust sliders, export
  6. Province Image tab -- generate provinces from territories, export
